* **W5 descriptor numbering:** DONE (B5). A guest number is an index into the adapter's table of objects (`vfd.h`: `Vt`, 4096 numbers) and has no relation to a WASI descriptor: the first `open()` is 3, every `open`/`dup`/`pipe`/`socket`/`F_DUPFD` gives the lowest free number, `dup2` takes any number below 4096 at no cost, `EMFILE` only when the table is full; the object holds its WASI descriptor, path, open flags and directory snapshot; no placeholder directories, no `fd_renumber` (the WASI import is gone: 33 WASI imports in the fused module, were 34), no preopen number is reachable (`is_pre` is gone); mmap keeps a reference to the object, not a number (`tests/test_descriptors.py`, the last six tests, with Pyodide's answers). Left: `F_DUPFD` with a minimum of 4096 or more is EINVAL (Pyodide accepts any), the last number is 4095 (Pyodide's `open` reaches 4096), and `os.set_inheritable(fd, True)` stays a no-op (the libc answers FIOCLEX itself).
* **W6** `st_nlink`, `st_blocks` differences (host-dependent). Still different in a listing (`files_dirs.py`): a name removed or renamed while a `scandir` loop runs is still listed (Pyodide skips what is gone); a 5000-name `listdir` takes 0.13 s where Pyodide takes 0.005 s (wasmtime's `fd_readdir` stats every entry).
* Known partial (platform limits, in the audit): `mknodat` FIFO/char/block/socket (WASI cannot create), `utimensat` outside 1970..2554 (WASI u64 ns), `symlinkat` across preopens (cap-std), epoll (3 `__syscall_epoll_*`: ENOSYS, no decision), `_emscripten_system` (ENOSYS on purpose: a shell would be a sandbox escape).
* A descriptor that is open but no directory (a pipe, a socket, a file, a standard stream) used as `dir_fd` with a relative path is ENOTDIR in every *at call (Linux; Pyodide says ENOENT for a pipe or socket and ENOTDIR for the rest, and EBADF is kept for a closed number); `utime` on a pipe, a socket or a standard stream is 0 (as Pyodide's `utime(1)`). A program that ends with all 4093 numbers in use fails in the wrapper (`pyodide_nojs_run` opens its status file after the program: EMFILE, status 255 / -1; Pyodide's `runPython` needs no descriptor). A dlopen'd side module that imports a WASI fd function outside `_wasm.WASI_ROUTED` would get raw guest numbers (none does today).
